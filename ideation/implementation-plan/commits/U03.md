## Sequential implementation steps

1. Read Q05's versioned report examples and bind displays to saved numerators/denominators, cohort IDs and census. Keep modes and evaluator versions separate; show zero denominators as N/A and missing evidence/labels as unverified.

2. Add Scorecard drilldowns from M1-M7 and critical counts to exact suite entries,
   attempted scenarios, setup failures, unverified attempts and unrun slots. Show
   first unedited analyst/drafter quality, selected-plan quality, human corrections
   and auditor errors as separate observations.

3. Add EvidenceDetails for frozen expected versus independently observed provider fields, IDs/counts/associations, provenance/completeness, stage/span history and emission-time claim verdict references. Explain later drift separately from a contradicted completion claim.

4. Present Q03/Q05's premature, outcome-contradicted, deduplicated false-completion and unverified-claim counts without recalculating them. Preserve report watermark/version and restrict raw private artifacts to authorized references.

5. Test rendered values and authorized navigation against the saved report: missing
	labels, absent S1, v1/v2 reports, both violation kinds on one claim, later
	drift, 0/0, failed/unrun slots and censored latency. Repeat keyboard, focus,
	contrast and three-viewport checks for opened drilldowns. Record source report
	and screenshots. If deferred, U02's basic measured summary remains required.
