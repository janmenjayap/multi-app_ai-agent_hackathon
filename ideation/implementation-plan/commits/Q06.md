## Sequential implementation steps

1. Freeze sanitized event/span projections with B01/Q03, correlation and deduplication IDs, outbox leases and bounded export retry policy. Use P1-owned dependency/config changes if an SDK is required. Keep versioned claim and evidence references without moving verdict authority to LangSmith.

2. Implement allowlisted stage, model/tool attempt, latency, error class, and version/hash metadata. Link run/attempt/span/claim IDs so a reviewer can trace a saved assessment back to the actual local observation. Export no credentials, raw recipient/source/model content, or private reasoning.

3. Implement asynchronous outbox export with lease fencing and idempotent external IDs. Remote outage, rate limits, timeout, and permanent failure retain local measurements and explicit export status. Store a remote trace link only after confirmed export.

4. Test nested redaction, duplicate exports, crash/restart, unavailable credentials/service, and unaffected local run/assessment/denominator results. Compare local reports with exporter disabled, available, and failed.

5. If included, record a scoped sandbox export smoke receipt and prove its UI links resolve to the correct local attempt. Otherwise record Q06 as deferred; required local trace inspection, expected/actual evidence and human labels remain mandatory.
