## Exact LLM call site and spawning contract

Implement the [agent/LLM integration specification](../07-agent-spawning-and-llm-integration.md),
especially its configuration, raw-response ordering, and retry/resume rules.
"Spawn" means one bounded invocation of a fixed backend role; A01 creates no
OS worker, dynamic agent pool, supervisor-model call, or shared conversation.

1. Export `createModelClient(...)` from **model.ts** and `invokeRole(...)` from
   **runtime.ts**. R01's `src/server/composition.ts` constructs/injects the client;
   A02/A03/A04 call `invokeRole`. Only model.ts invokes Gemini
   `models.generateContent`. Roles, routes, and browser code do not call Gemini
   directly. Consume F02's `AgentInvocationContext`, `AgentCallResult<T>`, role
   schemas, and error enum; do not define a competing shared contract.
2. Use F01's validated `PG_MODEL_MODE=mock|live`, `GEMINI_API_KEY`, `GEMINI_MODEL`
   and optional role overrides plus `PG_MODEL_*` budget values. In live mode use
   one direct, non-streaming Gemini REST request with `responseMimeType` set to
   `application/json`, the Zod-derived `responseJsonSchema`, one candidate, no
   tools, and no provider SDK retry layer. Require a tested model/schema
   configuration; no default model-access claim or fallback from live to
   fixtures. F01 owns configuration/dependency edits.
3. `dispatchStructured(...)` accepts one attempt's messages/schema, deadline
   signal, and raw-response persistence callback. Capture and await restricted
   response-body persistence before provider-envelope parsing, including
   error/safety-block bodies. A transport stub must prove raw-save completes before parsing,
   invalid parsing preserves bytes, and storage failure prevents retry/progression.
4. Compute/verify a stable `roleInvocationKey` from `(runId, planRevision, role)`.
   Compare immutable input/source/upstream-result/prompt/schema/model digests on
   reuse; mismatch requires a new revision. B01 provides the unique claim,
   committed result, append-only attempts and persisted deadline/budget. Reentry
   returns an existing validated result without a network call. An interrupted
   dispatched attempt remains observable and any permitted replacement consumes
   the original budget with a new `modelAttemptId`.
5. Bound the complete input, output-token ceiling, per-call timeout, total role
   deadline, and combined transport/schema attempt count. Abort on cancellation,
   clamp to remaining run time, and never renew budgets on graph resume. A01 owns
   retry classification; semantic/policy rejection, refusal, bad credentials,
   unsupported schema/configuration and persistence failure are not blind retries.

**Integration acceptance:** instrument a fake HTTP client to assert Gemini
`generateContent` routing, the configured model/output limit, header-only API
key, no `tools`/remote MCP attachment, one HTTP request, and one `modelAttemptId`
per dispatch. Invoke the same key
twice and after a simulated checkpoint lag: one saved result, zero extra calls.
Exercise a permitted retry and show both attempts under the same role invocation.
Missing live credentials fail before dispatch; mock mode creates no network
traffic. The application [MCP/API boundary](../08-mcp-api-and-external-app-integration.md)
belongs to deterministic provider adapters, not this model client.

## Original-output and model-attempt measurement

This is the model producer for the [reliability plan](../06-agent-reliability-implementation.md), not a semantic ground-truth evaluator.

1. Open stage/span and per-attempt start records before invoking the client. Use canonical runtimeAttemptId for the graph invocation and distinct modelAttemptId for each model attempt; providerAttemptId belongs only to tools. Legacy attemptId is mapped by the F02 reader, with conflicts rejected. Record prompt/model/schema versions, input source refs/digests, UTC/monotonic duration, token usage when available, result/refusal/parse/transport errors and scheduled retry delay. Aborted processes leave an observable unfinished attempt.
2. Persist the first raw response before parsing, repair or retry, including malformed text and refusals. Store restricted content separately from redacted trace metadata; return immutable artifact references and digests to A02–A04/B03.
3. Preserve one first-proposal identity across corrected outputs and transport/schema attempts, while recording every actually dispatched attempt. Do not count retries as new task/evaluation attempts or replace an original bad result with a later valid JSON result.
4. Expose source/output records for Q05's actual human review. Labels bind reviewer identity/reference, reason, source/output digest, per-claim findings and supersedes references through the F02/B01 seam; the wrapper cannot generate a human label.
5. Test schema-invalid first output followed by corrected success, refusal then exhaustion, sink failure before call, crash after call start, and wall-clock changes under a monotonic total budget.

**Additional acceptance:** every real model call joins to recorded inputs, immutable raw result or unresolved/error state, and distinct attempt timing. First outputs remain recoverable byte-for-byte after retry/restart; synthetic model fixtures and actual model calls remain separate evidence. Q03 receives model telemetry; Q05 receives reviewable original outputs.
