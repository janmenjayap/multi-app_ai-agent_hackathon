## Reliability contracts to freeze in this commit

Use the [shared handoffs](../05-contracts-and-handoffs.md) and [detailed reliability plan](../06-agent-reliability-implementation.md) as the single reviewed specification.

1. Freeze the canonical event envelope: run/evaluation identity and canonical v2 runtimeAttemptId; stage, span and parent-span IDs; logicalCallId, modelAttemptId for model attempts and providerAttemptId for tool attempts; UTC timestamps, process/boot identity and monotonic elapsed values; causality references; schema/producer versions. Map legacy attemptId to runtimeAttemptId only through the explicit compatibility reader and reject conflicting values. Model/tool start, result, error, retry-scheduled, guard, verification and claim records remain distinguishable.
2. Define immutable raw-output/source artifact references and digests, prompt/model/schema versions, first-output identity, and append-only corrections. Review labels bind reviewer ID/reference, reason, source/output digests, per-claim findings and any superseded label. A producer cannot assert that a model label is an actual human review.
3. Define complete provider observation receipts with collection windows, scope, account reference, query/page coverage, response references/digests and producer identity. Keep existing evidence modes unchanged; authenticity is a separate trusted ingestion boundary and cannot be selected by an imported mode string.
4. Define stable success claim IDs, exact claimed scope, emission time/causal position, and verification references. Artifact-producing run claims require their plan and final Slack verification; typed no_affected claims instead require complete source/selection-empty and absence predicates, omit planRef, and require no final Slack artifact. Keep legacy falseCompletion semantics versioned as v1; the new evaluator separates prematureSuccessClaims, outcome confirmed/contradicted/unverified, and the deduplicated union by claimId.
5. Support typed logical EffectIdRef values for IDs unavailable before creation and a distinct ApprovedContentRef for generated text. Q01 freezes semantic facts/invariant predicates before model execution; B03 freezes exact generated bytes/digests in an immutable approved plan before dispatch. B07/Q02 resolve content references only from that plan receipt and ID references only from independent unique identity/marker receipts. Preserve the frozen logical manifest hash, plan/content and ID-binding receipts, and a separate concrete checker-export hash. Never derive expected owner/recipient/body/status from observed provider records.

**Additional acceptance:** reject orphan spans, conflicting legacy/v2 runtime IDs, model/tool attempt-ID misuse, cross-attempt claim bindings, forged trusted provenance, overwritten first outputs, missing review reasons, ambiguous logical-ID bindings, content refs resolved from provider output, and no_affected claims lacking complete empty-selection/absence evidence. Test old persisted inputs plus the explicit new-version path. F02 owns shared types; B01 owns persistence, producers own observations, and Q03/Q05 own evaluation logic after this seam is reviewed.
