## Frozen expectations, claims, and approval evidence

Apply the [reliability plan](../06-agent-reliability-implementation.md)'s distinction between approved content and independently evaluated truth.

1. Freeze the first analyst/drafter output references and source digests alongside the final proposal revision. Human or model correction creates a separate revision with reason; it cannot erase the original result used by M7.
2. Record each permitted artifact/content obligation and exact scope. Q01 freezes source facts and semantic invariants before the model call; it cannot predict exact generated wording. Resolve ApprovedContentRef only to exact normalized bytes/digests in this immutable approved plan before dispatch. Provider-created IDs use the distinct EffectIdRef or predeclared link substitutions and resolve from unique independent marker/identity bindings; no observed owner, recipient, body or status may be copied into expected predicates.
3. Preserve the pre-run logical manifest hash, approved plan/content hash and content-binding receipt, and independent ID-binding receipts; any concrete checker export receives its own hash. Resolving ApprovedContentRef freezes exact wording without changing Q01's independent semantic facts. Filling a permitted destination ID does not authorize arbitrary changes to approved bytes or a new semantic expectation.
4. Supply server-owned artifact/run success-claim scope templates for B07; models may propose content, but cannot assert verified execution. Runtime claim IDs/emission receipts are created later by the guarded workflow and reference actual verification records. The earlier no_affected path bypasses plan creation: its typed claim omits planRef and binds complete source/selection-empty and absence evidence, not a fabricated empty approved plan.
5. Extend tampering tests with ambiguous marker binding, content bound from observed Gmail bytes instead of the approved plan, wrong plan/content digest, undeclared substitution, changed citation/source digest, and a corrected draft whose first-proposal reference must remain unchanged.

**Additional acceptance:** B05 displays the exact approval-bound revision, B06 resolves only declared substitutions, and B07/Q02 can independently test the unchanged logical obligations. Q01 owns the evaluation oracle; a plan cannot reduce its expected artifact set or rewrite its expected outcome after execution.
