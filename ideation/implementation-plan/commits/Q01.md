## Sequential implementation steps

1. Freeze the complete suite census in `scenarios.json`: 18 family baselines, the six families requiring four additional attempts, named safety variants, and correction/repair legs. Store scenario, repetition, variant, eligibility, expected terminal state, fault boundary, budgets, versions, and mode separately from attempted execution records. The 42 baseline/repetition slots are targets, not observations.

2. Independently author source facts, forbidden claims, semantic content invariants, code-selected owner/recipient/status constraints, allowed effects, protected Beta records, and stage boundaries before any model invocation. Exact generated draft bytes do not exist yet and must not be invented as a pre-run oracle. Retain oracle reviewer identity/reason and source snapshot digests. Generated positive `human` labels stay synthetic fixtures.

3. Reuse the manifest validator under F02's observation schema v2. Freeze a logical manifest/hash using `EffectIdRef` for future-created provider objects and distinct `ApprovedContentRef` for generated exact content. B03 binds the latter to its immutable approved plan/bytes before any dispatch; Q02 resolves that frozen plan receipt, never provider-returned text. Independently observed unique marker-to-provider-ID receipts resolve only object IDs. A separately hashed resolved export never replaces the original manifest hash or relaxes source facts/semantic invariants.

4. Build stateful provider fakes independent of executor caches and expected-output generation. Reader APIs must expose records/history, pagination, actor/time metadata, and missing scopes. Support wrong-field acknowledgements, page-two failure, accepted unknown writes, duplicate creations, later human drift, and phantom Slack success. A fixed fake model remains simulated mode.

5. Add operator-only scoped seed/reset utilities with exclusive namespace ownership. Record setup separately from scored windows; source edits and repair stages are actor-tagged and predeclared. Agent capabilities cannot call cleanup utilities.

6. Add manifest/fake tests that reject absent artifacts, incomplete required fields, mutable oracles, ambiguous ID bindings, content bound after dispatch or from provider output, omitted cohort slots, and caller-generated review provenance. Include `no_affected` manifests whose complete source/selection evidence proves zero eligible commitments and no protected writes without requiring plan/approval/Slack artifacts. Verify deterministic fault replay and the original monitor/checker regressions. Hand F02-valid canonical scenario/world examples and their identities to every lane; U01 separately owns browser-only state fixtures and does not wait for Q01 to merge.
